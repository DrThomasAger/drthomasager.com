Every prompt written today borrows its structure from somewhere else —
markdown headings, XML tags, JSON braces. Each borrowed syntax arrives
carrying the habits of its home: documents, data, configuration. None of
them were made for the thing prompting actually is, which is one mind
addressing another in structured goodwill.

> A prompt language built from the ground up can make its hierarchy of
> attention visible in its own anatomy — so the structure itself says what
> matters most, before a single instruction is read.

## What a native prompt language changes

When structure is native, three things become possible at once. Sections
can carry their own tone. Emphasis can be graded rather than shouted. And
the reader — the model — meets a shape that was drawn for it.

## Key Takeaways

- Borrowed syntax carries borrowed meaning into every prompt.
- A native prompt language lets structure itself express attention.
- Goodwill can be encoded structurally, not just stated.
