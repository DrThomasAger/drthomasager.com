# Wave 4 – U.G. Krishnamurti in Indian languages

Catalogue of Telugu, Kannada, Hindi, Marathi, Tamil, Malayalam, Gujarati and Bengali material on **U.G. (Uppaluri Gopala) Krishnamurti** (1918–2007). Jiddu Krishnamurti material was excluded. Compiled 2026-10-24 from 37 web searches in native scripts and transliteration; the search budget was exhausted before Kannada-translation, Telugu-YouTube, Hindi-YouTube, Malayalam and Gujarati follow-ups could be run (see gaps per section). JSON companion: `scratchpad/json/wave4-indian-languages.json`.

Confidence: **S** = seen directly in a search result; **lead** = single/indirect source, needs verification.
