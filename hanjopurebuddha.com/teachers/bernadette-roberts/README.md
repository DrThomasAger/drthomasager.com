# Bernadette Roberts — source archive

The second teacher folder of hanjopurebuddha.com. Bernadette Roberts
(1931 – 27 November 2017), the Carmelite-trained American contemplative
who wrote of the passage beyond the unitive state in which the self falls
away entirely. Not any other person of the same name.
