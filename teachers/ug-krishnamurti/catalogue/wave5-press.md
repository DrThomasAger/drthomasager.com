# U.G. Krishnamurti — Wave 5 catalogue: press (newspapers, magazines, web press)

Scope: Uppaluri Gopala Krishnamurti (1918–2007) only; Jiddu Krishnamurti excluded. Compiled 2026-10-24. Companion data: `scratchpad/json/wave5-press.json` (50 items).

**Method note.** The shared WebSearch budget for this turn (200 calls, shared across agents) was already exhausted when this wave started; none of the ~40 planned searches ran. This file therefore consolidates every press item already surfaced by waves 1–4 (search snippets only; no pages were fetched) and records the brief's remaining targets as explicit leads/gaps, so the next wave can start from a clean target list. Confidence: **S** = URL seen directly in an earlier wave's search results; **lead** = named in the brief or in the official clipping index but no URL recovered.
