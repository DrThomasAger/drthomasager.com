Command in the Smile Prompt Language, the /C- Family and Every Composition as a Command

In THE MAP, a command is a destination, one row saying where the render goes, how it travels and when it fires. Every command name opens with the face C-.

Dr Thomas Ager18 October 20266 min read

(claude wrote this for me)

THE MAP makes every composition commandable. A command is a composition given a destination row, and one composition may be several commands, with custom behaviour through the settings, conditions and variables every composition carries. A multi-stage command is a composition of prompts sent in linear order, the join between its pieces being the turn boundary, walked by a cue naming the next command. A command waits for the turn, a message arrives at the next tool boundary, and stopping the work sits above both. A command may carry an importance shift, such as /Plan --VeryImportant, and lenses are over the commands, each mapping what an emoticon corresponds to for that lens.

Slash commands came to Smile on my PC in August 2026, first as something to record. On 6 August, “I want every time a command to be uesd to be recorded and available to everyone when it is a manual use.”1 On 11 August I listed the first family, “/Plan --VeryImportant, which we will parse as shifting the importance change.”, with /Send, /Research, /Confirm, /Bodhisattva, /Inheritance, /Doula and /Propose.2

Questions

What is a command in Smile?

A composition given a destination row, saying where its render goes, how it travels and when it fires. Every Smile command name opens with the face C-.

What is a multi-stage command?

A composition of prompts sent in linear order, each stage ending with a cue that names the next command for the model to invoke.

What does /C- do?

In my words of 22 August 2026, it lets you add any text on the end and wraps the whole thing in a Smile header and footer.
