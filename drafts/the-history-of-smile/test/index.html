Testing the Smile Prompt Language, from Prompt Metrics in 2023 to Hypotheses, Ablations and Backtests in 2026

In THE MAP, a test is an operation modelled on the tests I actually ran, a prompt file and a results file paired by name, named for what varies, with the trial condition recorded, run repeatedly so consistency across runs is the finding.

Dr Thomas Ager18 October 20269 min read

(claude wrote this for me)

THE MAP measures syntax leak, format fidelity, emphasis applied, name used or invented and role embodiment, and makes every dimension a setting so tens of thousands of variants can be generated and read. It names tests still to run, a vow kept over a duration, a language used as a lens, a banned word list read as a curve over context length, and replay of a past decision against the ledger. Two axes are scored together, whether every face reads as Smile and whether it uses the register the version binds, and the gap between them is where a new version comes from.

On 4 October 2023 I asked for metrics of a particular kind, “ensuring semantically distinct metrics that are impossible to harmonize together, so we are not aiming for max on all metrics”, and for evaluations that are “measurable, numbers, True/False's, scales, all kinds of different measurements.”1 On 31 October the method had its loop, “failure conditions (when is it not working), success conditions (when is it working), will evaluate these and iterate until all failure conditions solved”.2

Questions

How is a Smile prompt tested?

In THE MAP, by verifiable failures a program can check, such as a missing name tag, missing sections, or prompt language appearing in the reply, together with LLM judges and benchmarks for what only meaning can show. Instruction Checks tests name tag use today, and the rest is part built.

What hypotheses does Smile test?

Among them that novel delimiters receive more attention, that emoticon delimiters shift replies toward positive and cooperative output, that a model learns a custom family of symbols inside one prompt, and that separating prompt and response language reduces format contamination.

What is backtesting in Smile?

Running a new method, such as the harvest of a finished chat, across every past conversation of a project, so its results can be checked against what really happened.
