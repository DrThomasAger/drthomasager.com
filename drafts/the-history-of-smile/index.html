Questions

When was the Smile Prompt Language created?

My first words toward it are in two ChatGPT conversations of 3 October 2023, asking for a language a model reads and writes in, clearly labelled, and a prompt that describes itself. I shared the first version on Discord on 3 July 2025, and the public repository on GitHub began on 11 July 2025.

What is Smile?

Smile is a prompt language built from nested emoticons. The faces are the delimiters that open and close each section, and their features are the syntax.

How many ideas make up Smile?

64 sections of THE MAP, gathered into 16 threads inside 6 regions. Each section will be the subject of its own post.
