Semantic Markdown, the Response Format of the Smile Prompt Language and Its Name Tag

In THE MAP, Semantic Markdown is Smile's response format. Section names are Markdown headings, curly braces mark what the model fills, required text is inserted in its own formatting, and the instructions for using the format are written in Smile.

Dr Thomas Ager18 October 20268 min read

(claude wrote this for me)

THE MAP gives the response a name tag that ends with [:. The square family is kept for response format instructions, so the tag refers back to every instruction labelled response format in the Smile body. The response ends with :], closing what the name tag opened, so every response is labelled at once as one that has adhered using Smile. The pair places Smile syntax inside the response itself, which re-aligns the generation toward adherence and goodwill as it is written. Both marks sit at known positions, so Smile real time is to strip them for a person who wants a natural reading, and the headings optionally with them.

In July 2025 the Smile documents separated the prompt language from the response language. The De-GPT document wrote “We use regular markdown for templating, as many engines render markdown.”,1 and in its Word version, “It’s essential that we provide the AI the format of our response for them to respond in.”2 On 20 July a document put the pairing in one line, “(: prompt language (= Smile, response language (= Semiotic markdown (:”.3 On 29 July I named it, “For response languages, I use semantic markdown. This is just markdown that integrates semantic and semiotic meaningful emojis to condense large amounts of information into small spaces.”4 Markdown was offered as an example, never a requirement, “All response langusges are comparible with (: Smile, we just provide markdown response language example.”5

A name tag and ordered sections with templates keeping thinking from degrading is the format at work in a reply.

Most thinking instructions are trivially simple, and often the thinking of the AI will simply repeat what you are asking, become overly concise, degrade over time. But for complex tasks or difficult problems we need many intelligent thoughts that may be domain specific, in a specific order, and we need to stop degradation over time. By using a name tag, structured sections in a specific order that include template areas for the model to fill in, and curly brace instructions for particular parts of the template, we enable the model to consistently follow complex instructions by adhering to the template, and can detect when this template is not being followed and so then repeat the prompt.

Questions

What is Semantic Markdown in Smile?

Smile's response format. Section names are Markdown headings, curly braces mark what the model fills, required text is inserted exactly, and the instructions for using it are written in Smile.

What does the [: at the end of a name tag do?

The square family is kept for response format instructions, so [: refers back to every such instruction. The reply closes with :], marking the whole response as one that has followed the format.

What is forced text?

Text the model must write word for word at a given place in its response, which raises how closely it follows the instruction around it.
